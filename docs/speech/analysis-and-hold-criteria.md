# 음성 분석 로직과 판정 보류 기준

작성일: 2026-10-02 · 분석 버전 `jamo-align-v1` · 엔진 whisper.cpp 1.9.4 + `ggml-large-v3-turbo-q5_0` + Silero VAD v5.1.2

## 1. 원칙

- **텍스트 일치율(`textMatchRate`)은 발음 정확도 점수가 아니다.** 음성 인식 모델이 적은 글자를 목표 문장과 비교한 값이다. 화면에서는 "텍스트 일치율"로만 표시하고, 발음 정확도·말하기 속도·유창성은 "미평가"로 둔다.
- 검증된 음소 평가 모델이 없으므로 **발음 점수를 만들지 않는다.** `pronunciation_score` 등은 외부 제공자(`SPEECH_ENGINE=external`)가 실제로 돌려준 값만 저장한다.
- 자동 분석 결과는 근거·후보다. 발음 판단의 기준은 선생님 검토(`teacher_judgement`, `teacher_confirmed_json`)이며, 두 결과는 서로 덮어쓰지 않는다.

## 2. 처리 흐름

| 단계 | 위치 | 내용 |
|---|---|---|
| 1. 녹음 | `useAudioRecorder`, `wavEncoder` | 브라우저 녹음(최대 30초) → 16kHz mono 16-bit WAV 변환. 녹음마다 `Idempotency-Key` 생성 |
| 2. 업로드·중복 방지 | `SpeechAnalysisServiceImpl` | 같은 학생·같은 키는 한 번만 분석(유니크 제약). 같은 키에 다른 녹음이면 409. 실패하면 키를 비워 재시도 허용 |
| 3. 사전 검사 | `LocalWhisperRecognitionService` | 길이 0.3~30초, 최대 진폭 300 미만(무음)은 추론 전 422 |
| 4. 말소리 확인(VAD) | `whisper-vad-speech-segments` | 앞뒤 1초 무음을 붙여 검사. 말소리 구간이 0개면 422(배경 소음에서 "감사합니다" 등을 만들어내는 것 방지). 구간 시각은 발화 시간 계산에 쓴다 |
| 5. 인식 | `whisper-cli -l ko` | 전체 녹음(+1초 패딩)으로 인식. 목표 문장을 프롬프트로 주지 않는다(정답 쪽으로 받아 적는 편향 방지). 환각 문구 목록에 걸리거나 빈 결과면 422 |
| 6. 텍스트 비교 | `TranscriptComparator` | NFC 정규화·문장부호 제거 후 음절 편집 거리로 `textMatchRate = (1 − 음절 오류율) × 100`(0 미만은 0). 어절 단위 일치·누락·첨가·대치 표시 |
| 7. 자모 비교 | `HangulPhonemeAnalyzer` | 목표·인식 음절을 자모 차이 비용으로 정렬해 초성·중성·종성별 대치/생략/첨가 **후보**, 음절 생략·첨가 후보. 문항의 목표 음소(`exercises.target_phonemes`) 위치(어절·음절·초성/종성·어두/어중/어말). 표기 기준이며 연음·경음화 등 발음 규칙은 반영하지 않는다 |
| 8. 발화 시간 | `SpeechAssessmentEvaluator` | VAD 구간으로 말소리 길이, 앞뒤 무음, 쉼 횟수·최장 쉼, 초당 음절(인식 텍스트 기준) |
| 9. 반복 비교 | 같은 클래스 | 같은 문항 최근 5회와 같은 인식 결과 수, 반복된 후보 |
| 10. 판정 보류 | 같은 클래스 | 아래 3절 기준에 하나라도 걸리면 `assessmentStatus=HOLD` + 사유 |
| 11. 저장 | `speech_analyses` | 일반 아동: 일치율 저장, 녹음 즉시 삭제. 언어재활 아동: 일치율 저장하지 않음, 녹음 보관(최대 6개월)·선생님 검토 대기 |

알려진 한계(테스트로 확인): Whisper는 틀린 발음을 맞는 단어로 고쳐 적는다("숩속을" → "숲속을"이면 일치율 100%). 반대로 "다디오"를 "타디오"로 적어 대치 후보가 ㄹ→ㄷ가 아니라 ㄹ→ㅌ로 나온다. 인식 신뢰도(token 확률)는 맞고 틀림을 구분하지 못했다(틀린 인식도 0.94~0.95).

## 3. 판정 보류 기준

| 사유 코드 | 조건 | 의도 | 합성음 검증 | 실제 아동 음성 검증 |
|---|---|---|---|---|
| `SPEECH_CUT_OFF_END` | 마지막 말소리 구간 끝 ~ 녹음 끝 ≤ 100ms | 말하는 도중 녹음을 멈춘 경우 | 확인함: 문장 앞 60%만 남긴 녹음, 브라우저에서 1.5초에 멈춘 녹음 모두 보류. 끝에 0.5초 무음이 있는 정상 녹음은 보류 안 됨 | **미검증** |
| `SPEECH_CUT_OFF_START` | 첫 말소리 구간 시작 ≤ 20ms | 말하는 중에 녹음을 시작한 경우 | 단위 테스트(가상 구간)만 | **미검증** |
| `SPEECH_TOO_SHORT` | 말소리 합계 < 200ms | 소리 일부만 잡힌 경우 | 단위 테스트만 | **미검증** |
| `CLIPPING` | ±32000 이상 샘플 비율 > 0.5% | 너무 큰 소리로 찌그러짐 | 단위 테스트만 | **미검증** |
| `LOW_VOLUME` | 최대 진폭 < 1500 (무음 기준 300 이상) | 너무 작은 소리 | 단위 테스트만 | **미검증** |
| `NON_HANGUL_TRANSCRIPT` | 인식 결과에 숫자·영문 | "20cm"처럼 표기 차이로 비교가 어려움 | 단위 테스트만 | 해당 없음(표기 규칙) |
| `LENGTH_MISMATCH` | 인식 음절 > 목표×2+1, 또는 목표 2음절 이상에서 인식 < 목표/2 | 반복 발화·다른 말·일부만 녹음 | 단위 테스트만 | **미검증** |

기준값의 근거: 합성음 녹음과 브라우저 녹음(가짜 마이크)에서 정상 녹음을 보류하지 않으면서 잘린 녹음을 잡는 값으로 정했다. 실제 아동 녹음에서의 오보류율(정상인데 보류)·누락률(잘렸는데 통과)은 측정하지 않았다. **판정 보류 기준의 아동 음성 검증은 미완료 항목이다.**

## 4. 실제 아동 음성 검증 계획 (미착수)

검증 데이터가 확보되기 전까지 위 기준은 합성음 기준값으로만 운영하며, 결과 화면은 "판정 보류/후보"로만 안내한다.

1. 적법성 확인(착수 전 필수)
   - 수집 목적(음성 분석 품질 검증), 항목, 보유 기간, 파기 방법을 명시한 **법정대리인 동의**(만 14세 미만)와 기관 승인. 서비스 이용 동의(VOICE)와 별도의 연구·검증 목적 동의를 받는다.
   - 공개 데이터(AI Hub "한국어 아동 음성" dataSetSn=540, "구음장애 음성인식" dataSetSn=608)는 이용 신청·약관(목적 외 사용·재배포 금지)을 따른다.
   - 개인정보 영향 검토, 가명 처리(이름·학교 등 발화 내용 포함 여부 확인), 접근 권한 최소화, 검증 종료 후 파기.
2. 정답 라벨: 언어재활사가 녹음마다 (a) 잘림 여부, (b) 음량·찌그러짐, (c) 목표 음소의 실제 산출(대치·생략·왜곡)을 표기.
3. 측정: 보류 사유별 오보류율·누락률, 자모 후보와 언어재활사 판정의 일치도(정밀도·재현율), 연령·조음 특성별 차이.
4. 기준 조정: 측정 결과로 임계값을 바꾸면 분석 버전(`analysis_version`)을 올리고 변경 근거를 이 문서에 기록한다.
