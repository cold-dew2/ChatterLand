- 화면 시각은 녹화 기록(`[timeline]`) 기준이며 ±1초 차이가 있을 수 있다. 영상 맨 앞 1초 이내에 빈 화면이 있으면 편집에서 잘라도 된다.

## 촬영 전 준비 데이터 (테스트 DB)

- 녹화 스크립트가 매번 새로 만든다: 선생님 '김선생님', 학생 '하늘'(8세, 일반 아동), 담당 연결. 이메일은 `e2e-contest-…@example.test` 형식의 가짜 주소(로그인 화면에 잠깐 보인다).
- 연습 콘텐츠: 기본 콘텐츠 "천천히 말하기"(유창성, 첫 문장 "오늘은 날씨가 좋아요.").
- 마이크 입력: `frontend/e2e-demo/mic-weather-demo.wav`(macOS 합성음 + 배경 소음 + 무음 4초).
- 필요한 것: 테스트 DB(`backend/scripts/test-db.sh start`), whisper.cpp 모델과 VAD 모델, Mailpit, 비어 있는 8080·3000 포트(녹화가 테스트 DB 백엔드와 프런트를 직접 띄운다). 개발 백엔드·개발 DB는 쓰지 않는다.

## 촬영 중 주의

- 화면 자막은 설명용 덧씌움이다. 발음 점수·평가 등급으로 읽히는 문구를 넣지 않는다.
- 텍스트 일치율은 '글자 비교 · 발음 점수 아님'으로, 말하기 속도·멈춤은 '녹음에서 잰 값'으로만 소개한다.
- 마이크 입력이 합성음이라는 자막(0:23 부근)을 빼지 않는다.
- 학생 결과 화면 아래쪽의 'AI 설명' 영역은 본 영상에 나오지 않는다(근거 자료 부족 상태, 아래 '제외').

## 제외한 기능과 이유

| 기능 | 이유 |
|---|---|
| AI 학습 설명(RAG + Gemini) | RAG 원문 자료 7개가 모두 내용 미승인(DRAFT)이라 검색 결과가 없고, 이때는 Gemini를 부르지 않고 '근거 자료 부족'을 돌려준다(`SpeechFeedbackServiceImpl`). 자료 승인·우회를 하지 않았으므로 시연할 수 없다 |
| 발음 정확도 점수 | 평가 모델이 없다. 화면은 '준비 중' |
| 아동 음성 측정 정확도 | 아동 음성으로 검증하지 않았다. 마이크 입력은 합성음 |
| AI 대화 | 실제 Gemini로 동작하지만 60초 안에 넣으면 장면이 너무 짧아져 보조 클립으로 따로 녹화했다(아래) |

## 보조 클립: AI 대화 (선택)

- 경로: 학생 로그인 → `/student/practice` → 'AI 대화하기' → 주제 '좋아하는 음식' → 입력 "나는 사과를 좋아해요" → '보내기' → 실제 Gemini 응답
- 실제 응답(2026-10-15, `gemini-flash-latest`, 8.2초): "사과는 아삭아삭하고 달콤해서 정말 맛있지요! 좋아하는 음식을 이야기해 줘서 고마워요. 사과의 어떤 점이 가장 좋아요?" 아래에 대화 낱말과 연결된 연습 3개가 표시된다.
- 자막: "AI 대화 · 실제 Gemini 응답 / 자동 생성 응답 · 품질 검증 전". 응답 품질을 검증한 것이 아니다.
- 호출: 메시지 1건 = Gemini 1회. '대화 끝내고 요약 보기'(추가 호출)는 누르지 않았다. 학생 계정은 AI 대화 외부 전송 동의(AI_CHAT)를 받은 시연용 테스트 계정이다.
- 본 영상에 넣으려면 0:30–0:43 장면 뒤에 붙이고 다른 장면을 줄여 전체 60초 이내로 맞춘다.
