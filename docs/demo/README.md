# 발표용 시연 영상 (2026-10-14)

- `chatterland-demo-2026-10-14.mp4`: 발표용(H.264, 1280×720, 43.6초, 소리 없음). Keynote·PowerPoint·QuickTime에서 재생된다.
- `chatterland-demo-2026-10-14.webm`: Playwright가 녹화한 원본(VP8). mp4는 이 파일을 Chrome MediaRecorder로 재인코딩한 것이며 편집하지 않았다.
- 다시 만들기: `frontend/e2e-demo/README.md`

## 흐름 (한 번의 실제 실행을 자르지 않고 녹화)

1. 선생님 로그인 → 제자 관리 → 시연 학생 → 숙제 배정(연습 콘텐츠 "천천히 말하기", 첫 문장 "오늘은 날씨가 좋아요.") → 저장 → 로그아웃
2. 학생 로그인 → 오늘의 숙제 → 연습하러 가기 → 녹음(약 4초) → 내 녹음 재생 바 표시
3. 분석하기 → 녹음 파일 서버 전송 → 로컬 음성 인식(whisper.cpp) → 목표 문장과 글자 비교 → 결과 표시·학습 기록 저장 → 히스토리 화면에서 다시 조회 → 로그아웃
4. 선생님 로그인 → 제자 관리 → 시연 학생 → 학습 현황 → 숙제 연습 기록(목표·인식 결과·텍스트 일치율이 학생 화면과 같음)

## 시연 조건(영상 자막에도 표시)

- **마이크 입력은 실제 아동 음성이 아니다.** Chrome 가짜 마이크로 합성음 파일(macOS `say -v Yuna` "오늘은 날씨가 좋아요." + 배경 소음 + 무음 4초)을 넣었다. 녹음·업로드·음성 인식·비교·저장은 실제 서버에서 실행되었다.
- 테스트 계정·테스트 DB(개발 DB 아님). 이메일은 `e2e-demo-…@example.test` 형식의 가짜 주소다.
- **발음 정확도 평가는 하지 않는다.** 텍스트 일치율(100%)은 음성 인식 글자 비교이며 발음 점수가 아니다(화면에 '발음 점수 아님', 발음 정확도 '미평가' 표시).
- 외부 AI(Gemini) 호출 없음. 학생 결과 아래 'AI 설명 · 근거 자료 부족'은 조회 결과다(승인된 RAG 자료가 없어 생성하지 않음).
- 자막(오른쪽 아래)은 화면 위에 덧씌운 설명이다. 자막 속 결과 값은 실제 화면에서 읽은 값이다. Next.js 개발 서버 배지는 가렸다.
